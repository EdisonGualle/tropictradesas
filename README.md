# 🌎 TropicTrade - Exportación de Banano  

**TropicTrade** es una empresa ecuatoriana especializada en la **exportación de banano** y frutas exóticas, cumpliendo con los más altos estándares de calidad.  
Este proyecto es su plataforma web oficial, desarrollada con **React + Vite**, proporcionando información clave sobre la empresa, servicios, contacto y presencia internacional.

---

## 📌 **Características Principales**
✅ **SEO Avanzado** con `react-helmet-async` y configuración en **Google Search Console**  
✅ **Lazy Loading con Suspense** para optimizar el rendimiento  
✅ **Gestión eficiente de imágenes y videos** con almacenamiento optimizado  
✅ **Rutas protegidas y manejo de errores personalizados**  
✅ **Diseño responsivo y animaciones modernas con TailwindCSS**  
✅ **Desplegado en Hostinger** con `.htaccess` optimizado  
✅ **Optimización de caché** para imágenes, videos y archivos estáticos (1 año)  
✅ **Compresión automática** con Gzip y Brotli  

---

## 🛠️ **Tecnologías Utilizadas**
- ⚡ **Vite** - Para una configuración rápida en React  
- ⚛️ **React.js** - Framework principal  
- 🎨 **Tailwind CSS** - Estilos modernos y responsivos  
- 🚀 **React Router** - Manejo de rutas dinámicas  
- 🛠️ **Lazy Loading con Suspense** - Para mejorar los tiempos de carga  
- 🔎 **Google Search Console y Schema.org** - Para mejorar la indexación en buscadores  

---

## 🚀 **Instalación y Uso en Desarrollo**
### 1️⃣ **Clonar el repositorio**
```sh
git clone https://github.com/tropictradesas/tropictrade-web.git
cd tropictrade-web
```

### 2️⃣ **Instalar dependencias**
```sh
npm install
```

### 3️⃣ **Ejecutar en modo desarrollo**
```sh
npm run dev
```

### 4️⃣ **Acceder a la web**
```
http://localhost:5173
```
